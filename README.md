# Student Recommendation Analysis

## Overview
This project analyzes quiz performance data to provide insights and recommendations for students. It identifies weak areas, highlights strengths, and proposes actionable improvement steps.

## Features
- Fetch data from APIs for current and historical quiz performance.
- Analyze topics, difficulty levels, and response accuracy.
- Generate student personas with strengths, weaknesses, and learning styles.
- Visualize performance trends with interactive charts.
